# Microsoft Activation Scripts (MAS)

An open-source Windows and Office activator featuring HWID, Ohook, TSforge, and Online KMS activation methods, along with advanced troubleshooting.

## 🚀 Features

* **HWID Activation:** Permanent Windows activation tied to your hardware.
* **Ohook Method:** Permanent Office activation utilizing the official hooks.
* **TSforge Method:** Advanced and secure activation alternative.
* **Online KMS:** Timed or renewal-based activation for various products.
* **Troubleshooting:** Advanced built-in tools to fix common activation errors.

## 🛠️ Activation Methods


| Method | Target Product | Permanence | Requirement |
| :--- | :--- | :--- | :--- |
| **HWID** | Windows 10 / 11 | Permanent | Internet Connection |
| **Ohook** | Microsoft Office | Permanent | No Internet Needed |
| **TSforge** | Windows / Office | Permanent | Advanced Setup |
| **Online KMS** | Windows / Office | 180 Days (Auto-renew) | Internet Connection |

## 💻 How to Use

Choose one of the methods below to run the scripts:

### Method 1: PowerShell (Recommended)
Right-click the Windows Start menu and select **PowerShell** or **Terminal** (Admin). Run this command:
```powershell
irm https://massgrave.dev | iex
```

### Method 2: Traditional Download
1. Download the latest release from the repository.
2. Extract the `.zip` file.
3. Run the `MAS_AIO.cmd` file as Administrator.

## ❓ Troubleshooting

If you encounter any issues during activation, follow these steps:
1. Open the MAS menu.
2. Select the **Troubleshooting** option.
3. Run the script diagnostic tool to repair your licensing files.
